# Финштаб — семейные финансы на телефоне

Приложение для учёта денег семьи по мотивам видео: записываешь траты и приходы, а панель сама считает **паспорт месяца** (личный доход и расход, норма сбережений, доля утечек), **темп месяца**, **свободные деньги**, строит **архитектуру расходов** (FIXED / LIFE / WANT / LEAK, бизнес отдельно), следит за **лимитами** и делает **разбор**: подписки, рост трат, прогноз накоплений на 12/36/60 месяцев.

- Работает как приложение: открывается с иконки на экране «Домой», на весь экран, без интернета.
- Дизайн в стиле Apple, светлая и тёмная тема.
- Вход по код-паролю, данные **зашифрованы** (AES-256) прямо на телефоне. Серверов нет.
- По желанию — **общий учёт для всей семьи** через ваш приватный репозиторий GitHub (тоже в зашифрованном виде).

## Как выложить на GitHub Pages (≈10 минут, бесплатно)

### Шаг 1. Аккаунт GitHub
Если аккаунта нет — зарегистрируйтесь: <https://github.com/signup>. Запомните **имя пользователя** (username) — оно будет в адресе сайта.

### Шаг 2. Создайте репозиторий для сайта
1. Откройте <https://github.com/new?name=finshtab&visibility=public> — форма заполнится сама.
2. Проверьте: **Repository name** = `finshtab`, видимость — **Public** (для бесплатного GitHub Pages сайт должен быть публичным; это только код приложения, ваших данных там не будет).
3. Включите **Add README** (так будет удобнее загружать файлы).
4. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы
1. Распакуйте архив `finshtab.zip` на компьютере.
2. Откройте распакованную папку `finshtab` и выделите **все файлы внутри** (Ctrl+A). Важно: перетаскиваем именно файлы, **не саму папку**.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Перетащите выделенные файлы в окно браузера и дождитесь загрузки всех 16 файлов.
5. Внизу нажмите **Commit changes**.

> Если GitHub спросит про замену `README.md` — соглашайтесь.

### Шаг 4. Включите GitHub Pages
1. В репозитории откройте вкладку **Settings** (шестерёнка сверху).
2. Слева выберите **Pages**.
3. В блоке **Build and deployment**: **Source** → `Deploy from a branch`, **Branch** → `main` и папка `/ (root)` → **Save**.
4. Подождите 1–3 минуты и обновите страницу: сверху появится **Your site is live at** `https://ИМЯ.github.io/finshtab/`. Это и есть адрес вашего приложения.

### Шаг 5. Установите на телефон
**iPhone (только Safari):**
1. Откройте адрес `https://ИМЯ.github.io/finshtab/` в Safari.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран „Домой“»** → **«Добавить»**.
4. Откройте Финштаб **с иконки** на экране «Домой».

> На iPhone данные в Safari и в установленном приложении хранятся раздельно. Поэтому сначала установите, а потом заводите код-пароль и вносите записи — уже в приложении с иконки.

**Android (Chrome):** откройте адрес → меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).

### Шаг 6. Первый запуск
1. **Начать** → придумайте код-пароль (4 или 6 цифр, или пароль из букв — «Параметры код-пароля»).
2. Выберите **«С чистого листа»** или **«Посмотреть на демо-данных»** (демо удаляется одной кнопкой).
3. Добавляйте операции кнопкой **＋** внизу справа.

## Семейная синхронизация (по желанию)

Чтобы муж/жена/дети вносили траты со своих телефонов, а панель считала общие цифры.

**На основном телефоне** — **Настройки → Семейная синхронизация**, там 3 шага с кнопками:
1. **Создать на GitHub** — откроется форма нового репозитория `finshtab-data`. Видимость — **Private** (приватный!) → **Create repository**.
2. **Создать токен** — откроется готовая форма токена (имя, бессрочный, право *Contents: Read and write* уже выбраны). Вам остаётся в блоке **Repository access** выбрать **Only select repositories** → `finshtab-data`, нажать **Generate token** и скопировать токен (`github_pat_…`).
3. Вставьте в приложение: репозиторий `ИМЯ/finshtab-data`, токен → **Подключить**.

**На других телефонах семьи:**
1. Откройте адрес приложения и установите на экран «Домой».
2. На первом экране нажмите **«Подключиться к семье»**.
3. Введите репозиторий, токен и **код-пароль семьи** (тот же, что на основном телефоне). Данные для подключения можно скопировать на основном телефоне: *Настройки → Синхронизация → Показать данные для подключения*.

Как это работает: в приватном репозитории лежат только **зашифрованные** файлы (`meta.json` и `ops-ГГГГ-ММ.json`). Без код-пароля их не прочитать даже владельцу аккаунта. Изменения с разных телефонов аккуратно объединяются, без интернета записи копятся и уходят позже.

## Обновление приложения
Если вы меняете файлы (например, Claude доработал приложение): загрузите новые файлы в репозиторий `finshtab` так же, как в шаге 3. В файле `sw.js` должна измениться строка `VERSION` (например, `finshtab-1.0.1`) — по ней телефоны узнают о новой версии и покажут баннер **«Доступно обновление»**.

## Безопасность и данные
- Код-пароль нигде не хранится. Ключ шифрования вычисляется из него (PBKDF2, 350 000 итераций) и живёт только в памяти, пока приложение открыто.
- Через минуту в фоне Финштаб снова попросит код-пароль (меняется в *Настройки → Автоблокировка*).
- **Забыли код-пароль — данные не восстановить.** Раз в месяц сохраняйте резервную копию (*Настройки → Резервная копия*) или включите семейную синхронизацию.
- Есть экспорт операций в CSV для Excel.

## Частые вопросы
**Сайт публичный — все увидят мои траты?** Нет. В публичном репозитории только код приложения. Ваши записи хранятся на телефоне (зашифрованы), а при синхронизации — в *приватном* репозитории, тоже зашифрованными.

**Свой домен вместо github.io?** Можно: *Settings → Pages → Custom domain* (понадобится купленный домен и настройка DNS у регистратора).

**Сменил телефон — как перенести?** Либо подключитесь к семейной синхронизации на новом телефоне, либо *Резервная копия → Сохранить копию в файл* на старом и *Загрузить копию из файла* на новом.

**Что значат уровни расходов?**
- **FIXED** — обязательное: аренда, ЖКХ, кредиты, налоги.
- **LIFE** — нужное: продукты, транспорт, здоровье, дети.
- **WANT** — качество жизни: кафе, покупки, отдых.
- **LEAK** — утечки: доставка, забытые подписки, комиссии.
- **Бизнес** — считается отдельно и в личный бюджет не входит (личный доход = все поступления − расходы на бизнес).
